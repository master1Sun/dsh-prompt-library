dsh-prompt-library — User Manual
================================

[1. What This Plugin Is]
A prompt management tool built into the chat interface. It saves, organizes, searches, and reuses the prompts you use often. Main parts:
- Library menu: the "Library" button above the settings button in the sidebar opens a centered panel whose left navigation reaches Data Management, Import/Export, Tag Manager, Recycle Bin, Persona Manager, and Skill Manager — each entry can be toggled in settings;
- Chat-box prompt button: a one-click entry beside the input box to insert or copy a prompt;
- AI polish button: one click on the input toolbar to polish selected text;
- # quick trigger: type # directly in the chat input to summon the library picker.
Everything runs locally (SQLite at ~/.dsh/prompt-library/db/prompts.db); nothing is uploaded to the cloud; export/import backups are fully under your control.

[2. Library Menu Panel]
- Location: above the settings button in the sidebar; click to expand/collapse. The panel scales with the screen and supports maximize;
- Data management: manage all prompts in one place — browse the list on the left (list/group views, search, tag filter), preview or edit on the right, create new prompts, insert into the current session, and AI-polish;
- Import/export: select a scope and export it as a backup file (pick any directory; the last location is remembered), or import to restore;
- Tag manager: create, rename, and delete tags centrally; tags in use cannot be deleted (current usage is shown);
- Recycle bin: soft-deleted prompts live here, with single or batch "restore / delete forever";
- Persona manager (lab feature): create and edit multiple personas (SOUL); once bound to a workspace/project, new sessions opened under that path automatically adopt the persona; unbound paths fall back to the default persona or an ancestor binding;
- Skill manager: configure prompts as session-level skills bound to a workspace/project path or the current session; matched ones are auto-injected. Supports scanning & importing from folders, AI-generated skill descriptors, exporting entries, and soft toggles for harness skills (the disabled list is injected into the system prompt).

[3. Chat-box Prompt Button & # Trigger]
- One click opens recent/frequent prompts and inserts directly into the current session;
- Type # to trigger the library picker: keep typing to filter live, ↑↓ to select, Enter to insert, Space or Esc to finish (can be disabled in settings);
- Whether the buttons show icon-only or with labels, and whether they show at all, is configurable in settings.

[4. Variable Templates]
- Use {{variable}} placeholders in the body, e.g. "In a {{tone}} tone, introduce {{topic}} to {{audience}}.";
- A fill-in dialog pops up on insertion; previous values are remembered per variable name and pre-filled next time.

[5. AI Capabilities]
- AI polish: refine selected text or a prompt body; the chat toolbar entry does not process {{}} variables, while other entries preserve them by default and may add new ones;
- AI summary/title: generate an intro when creating or saving a prompt;
- Model selection: pick the AI provider and model in settings; "Auto-select (recommended)" is the default, and available models are polled automatically when one is unavailable.

[6. Context Recommendations & Selection Capture]
- Context recommendations (toggleable): when the input is empty, matching prompts are recommended above the input based on recent chat context; click to insert into the draft;
- Add-prompt-from-selection (off by default, enable in settings): highlighted text in chat shows an "Add to library" button; a standalone window lets you fill in title/tags/body and save, or just copy the selection.

[7. Data & Safety]
- Scheduled backups (experimental, off by default): once enabled, the database is backed up to the backup directory on the chosen schedule (daily/weekly/monthly); files beyond the retention count are auto-pruned; format is either a full db copy or readable JSON (restorable on its own);
- Storage cap: set the maximum number of stored prompts; when exceeded, auto-learned entries and the oldest ones are evicted first;
- Delete confirmation: every destructive action goes through a custom confirm dialog to prevent accidents;
- Updates: check for updates in settings, or enable "Auto update" to silently install new versions in the background.

[8. FAQ]
Q: Nothing changed after saving?
A: Make sure dsh web was restarted so the new version takes effect; panels refresh automatically after each save.

Q: AI polish does nothing?
A: AI features require an available LLM. If it says "AI service unavailable", check the model configuration.

Q: Where is my data? Can it be lost?
A: Local SQLite (~/.dsh/prompt-library/db/prompts.db). Back up regularly via "Import/Export → Export", or enable scheduled backups.

Q: Can't delete a tag?
A: The tag is still used by prompts. Remove it from those prompts first; the protection mechanism blocks deleting tags in use.

Q: Where did the slash commands go?
A: The /prompts slash commands were removed in the new version. All capabilities now live in the library menu panel, the chat-box buttons, and the # trigger — just as complete and far more discoverable.
